لطفاً بک‌اند اپلیکیشنی که رابط کاربری Next.js آن آماده است را با استفاده از Node.js/Express پیاده‌سازی و با UI موجود یکپارچه کن. اسکرین‌شات رابط کاربری در اختیار شما قرار گرفته است تا ترتیب فیلدها و دکمه‌ها را ببینی.

**شرح وظایف:**
1. **پیکربندی پروژه:**
   - از Express برای ساخت سرور استفاده کن.
   - کلید API برای Freepik (مقدار = "FPSXc0ad36712014469ca51397930c8033ad") را به صورت امن به‌عنوان متغیر محیطی `FREEPIK_API_KEY` ذخیره کن و در کد هرگز آن را به‌صورت ثابت ننویس.

2. **آپلود و میزبانی تصاویر:**
   - بک‌اند باید تصاویر بارگذاری‌شده از فرانت‌اند (تصویر اول و آخر) را دریافت کرده و آنها را طوری ذخیره کند که URL عمومی ایجاد شود (می‌توان از Cloudinary یا فولدر استاتیک Replit استفاده کرد).
   - مسیر آپلود تصاویر را ایجاد و URL‌های تصاویر ذخیره‌شده را به‌عنوان `firstImageUrl` و `lastImageUrl` به مراحل بعدی ارسال کن.

3. **ساخت endpoint برای تولید ویدئو:**
   - در مسیر `/generate` یا مشابه، درخواست POST را دریافت کن که شامل `prompt` (متن راهنما)، دو تصویر آپلودشده، تعداد ویدئوهای مد نظر کاربر (۱ تا ۳) و کیفیت انتخابی (۱۰۸۰p یا ۷۲۰p) است.
   - بر اساس کیفیت انتخاب‌شده، مقدار `duration` را تعیین کن: اگر ۱۰۸۰p باشد مدت‌زمان ویدئو ۵ ثانیه است و اگر ۷۲۰p باشد ۸ ثانیه:contentReference[oaicite:0]{index=0}.
   - به اندازهٔ `n`‌ ویدئو (۱ تا ۳) درخواست‌های جداگانه و هم‌زمان به اندپوینت `https://api.freepik.com/v1/ai/image-to-video/pixverse-v5-transition` ارسال کن. هر بدنهٔ درخواست شامل:
     - `prompt`: متن واردشده توسط کاربر
     - `first_image_url` و `last_image_url`: URLهای تصاویر آپلودشده
     - `resolution`: یکی از `720p` یا `1080p`
     - `duration`: ۵ یا ۸ (بر اساس کیفیت انتخابی)
     - `seed`: عدد تصادفی متفاوت برای هر درخواست جهت تنوع خروجی‌ها
   - از کتابخانهٔ `axios` برای ارسال درخواست‌ها و از `Promise.all` برای اجرای هم‌زمان آنها استفاده کن.
   - هدر `x-freepik-api-key` را با مقدار متغیر `FREEPIK_API_KEY` ست کن.
   - پاسخ هر درخواست را که شامل `task_id` و `status` است ذخیره کن و به فرانت‌اند بازگردان.

4. **پیگیری و نمایش وضعیت تولید ویدئو:**
   - توابعی بنویس که با استفاده از `task_id`ها به اندپوینت GET مربوطه مراجعه می‌کنند تا زمانی که فیلد `generated` حاوی لینک ویدئو شود. می‌توانی از بازه‌های زمانی (مثلاً هر چند ثانیه) برای استعلام وضعیت استفاده کنی.
   - پیشرفت ساخت هر ویدئو را به‌صورت درصدی یا در قالب یک نوار پیشرفت به فرانت‌اند ارسال کن تا در UI کاربر نمایش داده شود.
   - پس از تکمیل، لینک‌های نهایی ویدئوها را در فرانت‌اند نمایش بده و امکان دانلود آنها را فراهم کن.

5. **یکپارچه‌سازی با رابط کاربری موجود:**
   - دکمه‌ها و فیلدهای آپلود موجود در UI را به متدهای بک‌اند متصل کن؛ مثلاً در رویداد Submit فرم از `fetch` برای ارسال داده‌ها به `/generate` استفاده کن و نتایج را در وضعیت کامپوننت ذخیره کن.
   - امکان انتخاب تعداد ویدئوهای تولیدی (۱ تا ۳) و کیفیت (۱۰۸۰p یا ۷۲۰p) را در رابط کاربری اضافه کن و داده‌های انتخاب‌شده را به بک‌اند بفرست.

6. **تست و بهبود:**
   - پس از پیاده‌سازی بک‌اند، اطمینان حاصل کن که تصاویر به‌درستی آپلود می‌شوند، درخواست‌های تولید ویدئو بدون خطا ارسال می‌شوند و ویدئوها پس از اتمام فرآیند در صفحه نمایش داده می‌شوند.
   - هر پیغام خطا یا وضعیت را در کنسول لاگ کن تا عیب‌یابی آسان‌تر شود.

کدهای لازم برای سرور Express و تغییرات فرانت‌اند را در فایل‌های مناسب پروژه ایجاد کن و از Tailwind CSS برای حفظ زیبایی رابط کاربری استفاده نما.
